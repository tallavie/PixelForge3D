Turn a 3D model into pixel-art sprites

PixelForge 3D is a free tool that draws a rigged 3D model and its animations as a pixel-art sprite sheet, ready for Unreal Engine. It runs in your browser, and your models never leave your computer.

Looks

One model, eight looks

Every sprite here was made by the app from the same walk animation of the demo character. Only the look and the size were changed.

Features

From the model to the sheet, in one place

The 3D view and the pixel art stand side by side, so you see every change the moment you make it.

🧊

Your own models

GLB, GLTF, FBX and OBJ with their skeleton, animations and textures. Drop the files on the page.

🎞

Animations and frames

Choose the clips, set how many frames each one gets and trim them. Hold, duplicate or delete any frame on the timeline.

🦴

Posing

Rotate any bone, for one frame or for the whole model, and save a pose as a sprite of its own.

🎥

Camera and directions

Front, back, side, top-down, isometric or the angle you are looking from, in 1, 4 or 8 directions.

🎨

Drawn, not shrunk

Every base colour of the model gets its own ramp of tones, warmer in the light and cooler in the shadow, and each pixel picks a tone.

👁

Eyes and mouths

Faces are captured a second time, much larger. Thin lines stay one pixel wide, and eyes are built from pupil, white and iris with a sparkle.

🧱

Materials

Mark each material as body, eyes and mouth, glow or hidden, and tint it.

🖌

Palettes and finish

Fixed palettes, dithering, outlines, inner lines, sharpening and two kinds of anti-aliasing.

📏

Sizes that fit

Recommended sizes for characters, items, bosses and props in every look, or any size from 4 to 1080 pixels.

💡

Normal maps

An extra sheet of surface directions, so the sprites react to the lights of your game.

📦

Made for Unreal Engine

The sheet comes with a Paper2D file that turns it into one sprite per frame, and a readme with the import steps.

🔒

Stays on your computer

Everything is done by your browser. No model, texture or sprite is uploaded anywhere.

Directions

Eight directions from one walk cycle

Pick top-down or isometric and the number of directions. Each direction gets its own row in the sheet, lit the same way.

📘 The full guide, step by step
Export

What you get

Press Create sprite sheet, then Download all. The ZIP holds everything for one model.

In the ZIP

  • The sprite sheet as a PNG, and one strip per animation.
  • A .paper2dsprites file for Unreal Engine.
  • A JSON file that describes every animation: frames, speed and looping.
  • The palette.
  • If you ask for it, a normal-map sheet, and a sheet of the glowing parts when the model has any.
  • A readme with the import steps for that export.

In Unreal Engine

  1. Enable the Paper2D plugin.
  2. Drag the .paper2dsprites file into the Content Browser, with the PNG beside it. Unreal creates one sprite per frame.
  3. Select the sprites and choose Create Flipbook.

The Paper2D file and the normal-map steps were written from the documentation and have not been tried in every Unreal version. If an import fails, please open an issue.

Run it yourself

Online or on your own computer

Online

  • A current desktop browser. It was built and tested in Chromium browsers such as Chrome and Edge.
  • A 3D model with a skeleton and animations. GLB is the format it has been tested with most.
  • No model yet? The app has a demo character and a demo item.

▶ Open the app

From the source

  • You need Node.js 20.19 or newer.
  • On Windows, start.bat installs what is needed and opens the app.
git clone https://github.com/tallavie/PixelForge3D
cd PixelForge3D
npm install
npm run dev
