# PixelForge 3D

Turn a 3D model and its animations into a pixel-art sprite sheet, in the browser.
Load a model, pick the animations and the camera angle, choose a look, and export a sheet that Unreal Engine (Paper2D) imports directly.

**Try it online:** https://tallavie.github.io/PixelForge3D/

Everything runs on your own computer. Models are never uploaded anywhere.

## What it does

- **Models:** GLB / GLTF (Draco and Meshopt included), FBX and OBJ, with their skeleton and animations. Drop the files on the page. GLB is the format it has been tested with most.
- **Animations:** choose which clips to export, how many frames each gets, trim them, and add animation files that share the skeleton.
- **Timeline:** every exported frame can be moved in time, held longer, duplicated or deleted, and can carry its own bone pose.
- **Posing:** rotate any bone, for one frame or for the whole model, and save a pose as its own sprite.
- **Camera:** front, back, side, top-down, isometric or any angle, in 1, 4 or 8 directions. One button takes the angle you are looking from in the 3D view.
- **Sizes:** recommended sizes per style for characters, items, bosses and props, or any size from 4 to 1080 pixels.
- **Export:** sprite sheet PNG, a `.paper2dsprites` file for Unreal, a JSON description of every animation, the palette, one strip per animation, and optionally a normal-map sheet so the sprites react to lights.

## Looks

The **Game sprite** style draws the sprite the way hand-made monster sprites are drawn instead of shrinking a render:

- Colour and light are kept apart. Every base colour of the model gets its own ramp of tones with a hue shift (toward yellow in the light, toward blue-violet in the shadow), and each pixel picks a tone.
- **Shading style** switches the whole look:

  | Style | Tones per colour | Character |
  |---|---|---|
  | Fire Red | 4 | Game Boy Advance look: large shadows, the deepest tone along the shaded contour, a light checkerboard where two tones meet, black outline with colour on the lit edges. 64×64, 16 colors. |
  | DS | 3 | Small clean shadows, gentle hue shift, coloured outline that turns black on the shaded side. |
  | Game Boy Color | 2 | One flat shadow, no highlights, black outline, 8 colors. |
  | Soft HD | 6 | Smooth form for sprites of 128 pixels and up, full color depth. |

- **Eyes and mouths** are captured a second time on their own, much larger than the sprite. Thin strokes (closed eyes, mouth lines) are redrawn as one-pixel lines, and eyes are built from their parts: pupil, white and iris each keep a pixel, the eye is drawn a little larger than on the model, and a highlight sits on the side of the light.
- **Materials:** each material can be marked as body, eyes / mouth, glow (fire, lights) or hidden, and tinted.

The classic styles are still there: **8-bit** (NES and Game Boy palettes), **16-bit** and **32-bit**, with fixed palettes (PICO-8, Commodore 64, Sweetie 16, DawnBringer, Endesga), dithering, outlines, inner lines, sharpening and two kinds of anti-aliasing.

## Running it

You need [Node.js](https://nodejs.org/) 20.19 or newer.

```
npm install
npm run dev
```

Then open http://localhost:5183. On Windows, `start.bat` does both steps and opens the browser.

`npm run build` writes a static site to `dist/` that works from any web server or subfolder.

## Using the sheet in Unreal Engine

The ZIP contains `README_Unreal.txt` with the exact steps for that export. In short:

1. Enable the Paper2D plugin.
2. Drag the `.paper2dsprites` file into the Content Browser, with the PNG beside it. Unreal creates one sprite per frame.
3. Select the sprites and choose Create Flipbook. Set each flipbook's frames per second from the list in the readme.

The `.paper2dsprites` format and the normal-map steps were written from the documentation and have not been tested in every Unreal version. Please open an issue if an import fails.

## What is not in this repository

No 3D models, textures, sprites or other game assets. The two demo models are generated by code.
Names of consoles and games describe a drawing style only. This project is not affiliated with or endorsed by Nintendo, Game Freak, The Pokémon Company or any other company.
If you convert models from a game, the rights to those models stay with their owners.
